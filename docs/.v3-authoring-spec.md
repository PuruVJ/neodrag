# Neodrag v3 Docs — Authoring Spec (FINAL, interaction-centric)

Single source of truth for the docs rewrite. The brand: **a small, composable, cross-framework, collab-first drag · drop · sortable · resize library.** Read the actual source under `packages/*/src` if unsure — never invent API.

## Information architecture (interaction-centric — NOT per-framework, NOT per-option)
The framework is a global switch in the URL (`/docs/<framework>/…`); every page shows the reader's framework via `<FrameworkSwitch>`. Pages:
- **Getting Started** (`/docs/<fw>`) — install (per framework) + first draggable + the mental model.
- **Draggable** — the drag capability + ALL its options inline.
- **Droppable** — drop zones + DropOptions.
- **Resizable** — resize handles + ResizeOptions.
- **Sortable** — reorderable lists/grids + SortableOptions + `row()`.
- **Extras** — the `use: []` extension seam + every built-in extension + authoring + the reactivity rule.
- **Collaboration** — the CRDT/collab layer.
- **Sensors** — keyboard / gamepad / pointer (engine-level).
- **Core** — the `Dnd` engine + capabilities (advanced / framework authors).
- **Migration** — v2→v3, from svelte-drag.

Options are explained INSIDE the relevant capability page (no per-option pages). There are no per-framework pages.

## HARD RULES — never write these (dead API)
❌ `draggable()` / `droppable()` / `resizable()` as Svelte **functions** (Svelte is class-based now). ❌ `@neodrag/*/plugins|/drop|/sortable|/resize`. ❌ `@neodrag/core/dnd` (it's just `@neodrag/core` now). ❌ `@neodrag/core/a11y` (a11y is the `ariaDrag` extension). ❌ `plugins: [...]`, `axis('x')`, `bounds(BoundsFrom…)`, `events()`, `Compartment`, `Length`/`SizeInput`, `Neodrag`, `defineDragPlugin`, `drag.target`, hand-written `data-sortable-key`, `touchAction()`/`scrollLock()`-for-text-selection.

## Imports — everything from the ONE framework package
`@neodrag/svelte` · `@neodrag/react` · `@neodrag/vue` · `@neodrag/solid` · `@neodrag/vanilla`. Classes, hooks, extensions (`scrollLock`, `controls`, `magnetic`, `snapToGrid`, `autoScroll`, `ghost`, `haptics`, `ariaDrag`), collab (`bindCollab`, `MemoryBackend`) — all from there. Tree-shakeable. Install: `npm i @neodrag/<fw>@next`.

## Per-framework idioms (VERIFIED — final)

### Svelte (`@neodrag/svelte`) — **classes** + attachment spread
```svelte
<script>
  import { Draggable } from '@neodrag/svelte';
  const drag = new Draggable({ axis: 'x' });
</script>
<div {...drag.attach}>Drag me</div>
{#if drag.isDragging}…{/if}
```
- `new Draggable(options)` → `.attach`, `.isDragging`. `new Droppable(options)` → `.attach`, `.isOver`. `new Resizable(options)` → `.attach`, `.isResizing`, `.size`. `new SortableList(options)` → `.attach`, `.row(key)`.
- **Reactive options = getters**: `new Draggable({ get axis() { return axis; } })` updates live (the wrapper tracks getters and pushes `update()`; the attachment creates the instance with options read `untrack`ed so it isn't recreated).
- Requires Svelte 5 (attachments).

### React (`@neodrag/react`) — hooks + ref
```tsx
import { useDraggable } from '@neodrag/react';
function Box() { const { ref, isDragging } = useDraggable({ axis: 'x' }); return <div ref={ref}>Drag me</div>; }
```
- `useDraggable → {ref,isDragging}` · `useDroppable → {ref,isOver}` · `useResizable → {ref}` · `useSortable → {ref, row}`. Reactive: put state in the options each render (the hook pushes `update()`).

### Vue (`@neodrag/vue`) — composables + `:ref`
```vue
<script setup>import { useDraggable } from '@neodrag/vue';
const { ref, isDragging } = useDraggable({ axis: 'x' });</script>
<template><div :ref="ref">Drag me</div></template>
```
- `useDraggable/useDroppable/useResizable/useSortable` → `{ ref, … }` (Vue refs). Reactive option values via getters: `useDraggable({ get axis() { return axis.value } })`.

### Solid (`@neodrag/solid`) — primitives + ref setter
```tsx
import { createDraggable } from '@neodrag/solid';
function Box() { const { ref, isDragging } = createDraggable({ axis: 'x' }); return <div ref={ref}>Drag me</div>; }
```
- `createDraggable/createDroppable/createResizable/createSortable` → `{ ref, … }` (`isDragging` is an `Accessor` → call it). Reactive via getters: `createDraggable({ get axis() { return axis() } })`.

### Vanilla (`@neodrag/vanilla`) — the classes ARE the API
```js
import { Draggable } from '@neodrag/vanilla';
const drag = new Draggable(node, { axis: 'x' });   // node FIRST here
drag.update({ axis: 'y' }); drag.destroy();
```
- `new Draggable(node, options)` → `.update(partial)`, `.offset`, `.isDragging`, `.destroy()`. `new Droppable(node, opts)`, `new Resizable(node, opts)` (`.size`), `new SortableList(container, opts)` (`.update`, `.row(key)`, `.applyExternal(op)`, `.presence()`, `.destroy`).
- ⚠️ Note the Svelte class is **options-only** (`new Draggable(options)`) while the core/vanilla class is **node-first** (`new Draggable(node, options)`).

## DragOptions (final — note the new built-ins)
| key | type | meaning |
|---|---|---|
| `axis` | `'x' \| 'y' \| 'both'` | lock to one axis |
| `bounds` | `'parent' \| 'viewport' \| HTMLElement \| {left,top,right,bottom} \| () => rect` | constrain movement |
| `grid` | `[number, number]` | snap offset to a px grid |
| `handle` | `string \| HTMLElement` | start only from here (querySelectorAll; trusted selector) |
| `cancel` | `string \| HTMLElement` | block starting from here |
| `disabled` | `boolean` | when true, drag never starts |
| `touchAction` | `string \| false` | **built-in**. CSS `touch-action` applied at bind so touch drags aren't stolen as scroll. Axis-aware default (`pan-y` for axis x, `pan-x` for axis y, `none` for free). `false` to leave it. |
| `userSelect` | `boolean` | **built-in**. Default true — sets `user-select:none` on the body during a drag (no text-highlight). `false` to allow. |
| `threshold` | `number` | px of movement before a drag starts (default 0) |
| `position` | `{ x, y }` | controlled/initial offset (bind reactive state to control) |
| `dragData` | `unknown` | payload drop zones read via `accepts`/`onDrop` |
| `use` | `DragPlugin[]` | tier-2 extensions (see Extras) |
| `onDragStart`/`onDrag`/`onDragEnd` | `(e: DragEventData) => void` | callbacks |

`DragEventData = { offset: {x,y}, node, input }`. touch-action + user-select are always-on (the only built-in "behaviors"); everything else is opt-in.

### DropOptions
`accepts?({dragNode,data})` · `collision?` · `priority?` · `hitExpand?` · `onEnter/onOver/onLeave/onDrop?(e: DropEventData)`. `DropEventData = { zone, dragNode, data, input }`. Drop auto-observes drag — no wiring.

### ResizeOptions
`minWidth/minHeight/maxWidth/maxHeight?` · `aspectRatio?: boolean|number` · `bounds?` · `disabled?` · `use?: ResizePlugin[]` (e.g. `preserveUnits()` for CSS units — resize is px otherwise) · `onResizeStart/onResize/onResizeEnd?(e: ResizeEventData)`. `ResizeEventData = { width, height, edge, node, input }`. **Handles** = child elements with `data-neodrag-resize-handle="<edge>"`, edge ∈ n/s/e/w/ne/nw/se/sw.

### SortableOptions
`items: T[]` · `keyOf: (item) => string` · `onReorder: (next, op) => void` · `onCommit?(op)` · `onTransfer?(op)` · `axis?` · `strategy?: 'list'|'grid'` · `group?` (cross-container) · `animation?: boolean|number` (FLIP) · `lift?` · `hysteresis?`. Items get the binding via **`{...list.row(item.id)}`** (Svelte/React/Solid spread) / `v-bind="row(item.id)"` (Vue) — NOT a hand-written `data-sortable-key`. `MoveOp = { itemId, afterId }`.

## Extras — the `use: []` extensions
Imported from the framework package. Built-ins: `magnetic(targets, radius?)`, `snapToGrid(size)`, `onMove(fn)`, `scrollLock(opts?)`, `controls({ allow?/block?: ControlFrom.selector('.h') })`, `autoScroll(opts?)`, `ghost(opts?)`, `haptics()`, `ariaDrag(opts?)`. Authoring: a `DragPlugin` = `{ name?, onStart?(ctx), onMove?(ctx): Point|void, onEnd?(ctx) }` (return `{x,y}` from `onMove` to override the offset).

**Reactivity rule (document this once, in Extras):** `use:` is a **static array** — built once, instances stay alive for the binding, so any internal extension state is preserved and `onStart`/`onEnd` stay balanced. To make an extension reactive, the hook reads live config: a custom inline extension closes over your `$state`/signal (`{ onMove: ({offset}) => snap(targets, offset) }`), or a built-in reads a reactive **object** you pass (`magnetic(cfg)` where `cfg = $state({targets})`). A bare primitive passed to a factory is captured by value and is NOT reactive — that's JS, not a limitation we can fix. Do **not** make `use:` itself a getter (it would rebuild the array and wipe extension state).

## Collaboration (the brand headline)
```js
import { SortableList, bindCollab, MemoryBackend } from '@neodrag/<fw>';
const [a, b] = MemoryBackend.pair('peerA', 'peerB');     // demo backend (swap for Yjs/Liveblocks)
const off = bindCollab(list, a);                          // local commits → ops out; remote ops → applyExternal
```
`bindCollab(list: SortableList, provider)` → teardown. `CollabProvider = { sendOp(op), onRemoteOp(h)=>off, sendPresence?(p) }`. Anchor-based `MoveOp` commutes; `list.presence()` for live cursors. Implement a `CollabProvider` over Yjs/Liveblocks/WebSocket.
