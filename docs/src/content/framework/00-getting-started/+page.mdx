Neodrag is a small, composable, cross-framework, collab-first toolkit for **drag**, **drop**, **sortable**, and **resize** — one consistent API across Svelte, React, Vue, Solid, and vanilla JS.

## Install

Everything ships from a single framework package. It's fully tree-shakeable — you only pay for what you import.

<FrameworkSwitch>
<div slot="svelte">

```bash
npm i @neodrag/svelte@next
```

Requires Svelte 5 (the wrapper uses attachments).

## Your first draggable

Each capability is a class (Svelte/vanilla) or a hook/primitive (React/Vue/Solid). Create it, attach it to an element, and read its reactive state.

<FrameworkSwitch>
<div slot="svelte">

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';

  const drag = new Draggable({});
</script>

<div {...drag.attach}>
  {drag.isDragging ? 'Dragging…' : 'Drag me'}
</div>
```

</div>
<div slot="react">

```tsx
import { useDraggable } from '@neodrag/react';

function Box() {
  const { ref, isDragging } = useDraggable({});
  return <div ref={ref}>{isDragging ? 'Dragging…' : 'Drag me'}</div>;
}
```

</div>
<div slot="vue">

```vue
<script setup>
  import { useDraggable } from '@neodrag/vue';

  const { ref, isDragging } = useDraggable({});
</script>

<template>
  <div :ref="ref">{{ isDragging ? 'Dragging…' : 'Drag me' }}</div>
</template>
```

</div>
<div slot="solid">

```tsx
import { createDraggable } from '@neodrag/solid';

function Box() {
  const { ref, isDragging } = createDraggable({});
  return <div ref={ref}>{isDragging() ? 'Dragging…' : 'Drag me'}</div>;
}
```

</div>
<div slot="vanilla">

```js
import { Draggable } from '@neodrag/vanilla';

const node = document.querySelector('.box');
const drag = new Draggable(node, {});
// drag.update({ axis: 'y' }) to change options, drag.destroy() to clean up
```

</div>
</FrameworkSwitch>

That's a free-moving box. Pass options to shape it — `axis`, `bounds`, `grid`, `handle`, and more — all covered on the [Draggable](./draggable) page.

## The mental model

Four ideas carry the whole library:

- **Options** shape one interaction. `{ axis, bounds, grid, handle, … }` configure a single draggable, droppable, resizable, or sortable. Sensible built-ins like `touchAction` (touch drags aren't stolen as scroll) and `userSelect` (no text highlight while dragging) are always on.
- **Capabilities** are the four things you can do: **drag**, **drop**, **resize**, **sortable**. Each is its own class/hook with its own options, and they compose — a sortable item can also be droppable, a resizable panel can also be dragged.
- **Extras** extend an interaction through the `use: []` seam — `magnetic`, `snapToGrid`, `scrollLock`, `autoScroll`, `ghost`, `haptics`, `ariaDrag`, and your own. They snap onto any capability without changing its core options.
- **Collab** is first-class. A `SortableList` emits anchor-based, commutative ops; `bindCollab` wires them to any provider (Yjs, Liveblocks, WebSocket) for real-time multiplayer reordering and live presence.
