A lightweight Svelte library to make your elements draggable with Svelte 5 **attachments** and the `{@attach}` syntax.

## Installation

```sh
npm i @neodrag/core@next @neodrag/svelte@next
```

Requires **Svelte 5**.

## Plugins

Import built-in drag plugins from `@neodrag/core/plugins` or `@neodrag/svelte/plugins` (not the main `@neodrag/svelte` entry). Drop and sortable helpers live under `@neodrag/svelte/drop`.

## Usage

Create a **`Draggable`** once in `<script>` (stable attachment), then attach it. Use **static** plugins in the array; wrap only dynamic parts in `() =>`:

### Basic

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';
  

  const drag = new Draggable({ plugins: [] });
</script>

<div {@attach drag.attachment}>Drag me around!</div>
```

### With plugins

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';
  import { axis, grid, bounds, BoundsFrom } from '@neodrag/svelte/plugins';

  const dragX = new Draggable({ plugins: [axis('x'), grid([20, 20])] });
  const dragBounds = new Draggable({ plugins: [bounds(BoundsFrom.parent())] });
</script>

<div {@attach dragX.attachment}>Horizontal only, snapped to 20px grid</div>

<div {@attach dragBounds.attachment}>Constrained to parent element</div>
```

### Reactive plugins

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';
  import { axis, position } from '@neodrag/svelte/plugins';

  let pos = $state({ x: 0, y: 0 });

  const drag = new Draggable({
    plugins: [axis('x'), () => position({ current: pos })],
  });
</script>

<div {@attach drag.attachment}>…</div>
```

### Reactive axis switching

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';
  import { axis } from '@neodrag/svelte/plugins';

  let currentAxis = $state<'x' | 'y'>('x');

  const drag = new Draggable({
    plugins: [() => axis(currentAxis)],
  });
</script>

<div {@attach drag.attachment}>
  Currently draggable on: {currentAxis} axis
</div>

<button onclick={() => (currentAxis = currentAxis === 'x' ? 'y' : 'x')}>
  Switch to {currentAxis === 'x' ? 'Y' : 'X'} axis
</button>
```

## Advanced examples

### Draggable modal with handle

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';
  import { controls, ControlFrom, bounds, BoundsFrom, events } from '@neodrag/svelte/plugins';

  let dragPosition = $state({ x: 0, y: 0 });

  const drag = new Draggable({
    plugins: [
      controls({ allow: ControlFrom.selector('.drag-handle') }),
      bounds(BoundsFrom.viewport()),
      events({
        onDrag: (data) => {
          dragPosition = data.offset;
        },
      }),
    ],
  });
</script>

<div {@attach drag.attachment}>
  <div class="drag-handle">⋮⋮ Drag Handle</div>
  <div>Modal Content</div>
  <div>
    Position: x:{dragPosition.x.toFixed(0)}, y:{dragPosition.y.toFixed(0)}
  </div>
</div>
```

### Dynamic grid snapping

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';
  import { grid, axis } from '@neodrag/svelte/plugins';

  let gridSize = $state(20);
  let lockAxis = $state<'both' | 'x' | 'y'>('both');

  const drag = new Draggable({
    plugins: [
      () => grid([gridSize, gridSize]),
      () => (lockAxis === 'both' ? axis(null) : axis(lockAxis)),
    ],
  });
</script>

<label>
  Grid size: {gridSize}px
  <input type="range" bind:value={gridSize} min="10" max="50" step="5" />
</label>

<label>
  Movement axis:
  <select bind:value={lockAxis}>
    <option value="both">Both X & Y</option>
    <option value="x">X only</option>
    <option value="y">Y only</option>
  </select>
</label>

<div {@attach drag.attachment}>
  Grid: {gridSize}px, Axis: {lockAxis}
</div>
```

### Card stack with events

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';
  import { events, bounds, BoundsFrom } from '@neodrag/svelte/plugins';

  let cards = $state([
    { id: 1, title: 'Task 1' },
    { id: 2, title: 'Task 2' },
    { id: 3, title: 'Task 3' },
  ]);

  let dragState = $state<{
    cardId: number;
    isDragging?: boolean;
    position?: { x: number; y: number };
  } | null>(null);

  const cardDrag = new Draggable({
    plugins: [
      bounds(BoundsFrom.parent()),
      events({
        onDragStart: () => {
          dragState = { cardId: 0, isDragging: true };
        },
        onDrag: (data) => {
          dragState = {
            cardId: dragState?.cardId ?? 0,
            position: data.offset,
          };
        },
        onDragEnd: () => {
          dragState = null;
        },
      }),
    ],
  });
</script>

{#each cards as card (card.id)}
  <div
    {@attach cardDrag.attachment}
    onpointerdown={() => {
      dragState = { cardId: card.id, isDragging: true };
    }}
  >
    {card.title}
    {#if dragState?.cardId === card.id}
      - Dragging at ({dragState.position?.x.toFixed(0)}, {dragState.position?.y.toFixed(0)})
    {/if}
  </div>
{/each}
```

## TypeScript

```svelte
<script lang="ts">
  import { Draggable, type DragEventData } from '@neodrag/svelte';
  import { axis, bounds, BoundsFrom, events, type Plugin } from '@neodrag/svelte/plugins';

  let dragData = $state<DragEventData | null>(null);

  const drag = new Draggable({
    plugins: [
      axis('x'),
      bounds(BoundsFrom.viewport()),
      events({
        onDrag: (data: DragEventData) => {
          dragData = data;
        },
      }),
    ] satisfies Plugin[],
  });
</script>

<div {@attach drag.attachment}>TypeScript-enabled dragging</div>
```

## Shared engine (optional)

Most apps only need `new Draggable({ plugins })`. For a custom default plugin stack or debugging, use the `Neodrag` class:

```svelte
<script>
  import { Draggable, Neodrag } from '@neodrag/svelte';
  import { axis } from '@neodrag/svelte/plugins';

  const engine = new Neodrag({
    onError: (e) => console.error(e),
  });

  const drag = new Draggable({ plugins: [axis('x')], engine });

  console.log(engine.instances.size);
</script>

<div {@attach drag.attachment}>Custom engine instance</div>
```

`Draggable` uses `Neodrag.shared` by default. Pass a custom `engine` when you need separate engines on one page (uncommon).

## Drop zones

For drag-and-drop targets, import from `@neodrag/svelte/drop` and use `Droppable` the same way as `Draggable`:

```svelte
<script>
  import { Droppable } from '@neodrag/svelte/drop';
  import { highlight } from '@neodrag/core/drop/plugins';

  const drop = new Droppable({ plugins: [highlight({ overClass: 'over' })] });
</script>

<div {@attach drop.attachment}>Drop here</div>
```

## Resizable

```svelte
<script>
  import { Resizable } from '@neodrag/svelte/resize';
  import { resizeHandles, sizeBounds } from '@neodrag/svelte/resize';

  const resize = new Resizable({
    plugins: [resizeHandles({ edges: ['e', 's'] }), sizeBounds({ minWidth: 100 })],
  });
</script>

<div {@attach resize.attachment} style="width:200px;height:120px">Resize me</div>
```
