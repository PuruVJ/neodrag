```sh
npm i @neodrag/core@next @neodrag/vanilla@next
```

Import built-in drag plugins from `@neodrag/vanilla/plugins`. Drop helpers from `@neodrag/vanilla/drop`; sortable from `@neodrag/vanilla/sortable`.

## Usage

Create a `Draggable` (or `Droppable` / `Resizable`) binding and call `.attach(node)`. Each binding uses `Neodrag.shared` by default — one delegated pointer layer for the page, same as the framework packages.

### Basic

```typescript
import { Draggable } from '@neodrag/vanilla';

const drag = new Draggable({ plugins: [] });
drag.attach(document.querySelector('#drag')!);

// later
drag.destroy();
```

### With plugins

```typescript
import { Draggable } from '@neodrag/vanilla';
import { axis, grid } from '@neodrag/vanilla/plugins';

const drag = new Draggable({
  plugins: [axis('x'), grid([10, 10])],
});
drag.attach(document.querySelector('#drag')!);
```

### Plugins defined elsewhere (TypeScript)

```typescript
import { Draggable, type DragPluginList } from '@neodrag/vanilla';
import { axis, bounds, BoundsFrom } from '@neodrag/vanilla/plugins';

const plugins: DragPluginList = [axis('y'), bounds(BoundsFrom.parent())];

const drag = new Draggable({ plugins });
drag.attach(document.querySelector('#drag')!);
```

## Reactive plugins

```typescript
import { Draggable } from '@neodrag/vanilla';
import { axis, grid } from '@neodrag/vanilla/plugins';

let currentAxis: 'x' | 'y' = 'x';

const drag = new Draggable({
  plugins: [() => axis(currentAxis), grid([10, 10])],
});
drag.attach(document.querySelector('#drag')!);

function switchAxis() {
  currentAxis = currentAxis === 'x' ? 'y' : 'x';
  drag.update();
}
```

### Multiple reactive slots

```typescript
import { Draggable } from '@neodrag/vanilla';
import { axis, bounds, BoundsFrom, grid } from '@neodrag/vanilla/plugins';

let currentAxis: 'x' | 'y' | 'both' = 'x';
let gridSize = 20;
let enableBounds = false;

const drag = new Draggable({
  plugins: [
    () => axis(currentAxis),
    () => grid([gridSize, gridSize]),
    () => (enableBounds ? bounds(BoundsFrom.parent()) : null),
  ],
});
drag.attach(document.querySelector('#drag')!);

function updateAxis(newAxis: 'x' | 'y' | 'both') {
  currentAxis = newAxis;
  drag.update();
}
```

## Event handling

Callbacks live on the binding options (not a separate `events()` plugin):

```typescript
import { Draggable } from '@neodrag/vanilla';

const drag = new Draggable({
  plugins: [],
  onDragStart: (data) => console.log('Started:', data.offset),
  onDrag: (data) => console.log('Dragging:', data.offset),
  onDragEnd: (data) => console.log('Ended:', data.offset),
});
drag.attach(document.querySelector('#drag')!);
```

## Drag controls

```typescript
import { Draggable } from '@neodrag/vanilla';
import { controls, ControlFrom } from '@neodrag/vanilla/plugins';

const drag = new Draggable({
  plugins: [
    controls({
      allow: ControlFrom.selector('.drag-handle'),
      block: ControlFrom.selector('.no-drag'),
    }),
  ],
});
drag.attach(document.querySelector('#drag')!);
```

## Sortable lists

```typescript
import { Draggable, Droppable } from '@neodrag/vanilla';
import { Sortable } from '@neodrag/vanilla/sortable';

const items = [{ id: 'a' }, { id: 'b' }];

const list = new Sortable({
  items: () => items,
  keyBy: (i) => i.id,
  onReorder: (next) => {
    items.length = 0;
    items.push(...next);
  },
});

const zone = new Droppable({ plugins: list.container() });
zone.attach(document.querySelector('ul')!);

for (const item of items) {
  const chip = new Draggable({ plugins: list.item(item.id) });
  chip.attach(document.querySelector(`[data-id="${item.id}"]`)!);
}
```

Helpers like `applySortableReorder` and `SORTABLE_ROW_ATTR` are exported from `@neodrag/vanilla/sortable`.

## Custom engine

Pass `engine` when you need separate instances (uncommon). Otherwise rely on the default shared engine inside each binding:

```typescript
import { Neodrag, Draggable } from '@neodrag/vanilla';
import { axis } from '@neodrag/vanilla/plugins';

const engine = new Neodrag({
  onError: (error) => console.error(error),
});

const drag = new Draggable({ plugins: [axis('x')], engine });
drag.attach(document.querySelector('#drag')!);

// engine.dispose(); // all bindings on this engine
```

### Low-level engine API

`Neodrag.shared.draggable(node, plugins)` still exists for advanced use. Prefer `new Draggable({ plugins }).attach(node)` so callbacks, threshold, and reactive `update()` stay consistent with Svelte/React/Vue.

## Cleanup

```typescript
drag.destroy(); // single binding
// or
engine.dispose(); // entire custom engine
```

## CDN (Unpkg / jsDelivr)

```html
<script src="https://unpkg.com/@neodrag/vanilla@next/dist/umd/index.js"></script>
```

```html
<div id="drag">Drag me!</div>
<script>
  var drag = new NeoDrag.Draggable({ plugins: [] });
  drag.attach(document.getElementById('drag'));
</script>
```

The UMD build exposes `Draggable`, `Droppable`, `Resizable`, and `Neodrag` on the `NeoDrag` global. Import plugin helpers from a bundled `@neodrag/vanilla/plugins` build in app code; the minimal UMD entry does not include every plugin.
