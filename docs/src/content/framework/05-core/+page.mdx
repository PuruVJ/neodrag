The core engine that powers all Neodrag framework implementations. Neodrag v3 uses a unified **`Neodrag`** class with a plugin-based drag and drop system.

## Installation

```sh
npm i @neodrag/core@next
```

## Overview

`@neodrag/core` implements tree-shakeable plugins, delegated pointer handling, and a single engine for both drag sources and drop targets. Framework packages (`@neodrag/svelte`, `@neodrag/react`, etc.) are thin wrappers around this API.

## Architecture

- **`Neodrag`**: Main engine — `new Draggable()`, `new Droppable()`, `dispose()`
- **Plugins**: `defineDragPlugin` / `defineDropPlugin` with lifecycle hooks
- **Event delegation**: Three global pointer listeners on the delegate element
- **Reactive reconcile**: wrappers call `engine.update` when plugin inputs change
- **`DragHandle`**: Per-element binding with `.update()` and `.destroy()`

## Neodrag

```typescript
import { Neodrag } from '@neodrag/core';
import { axis, grid } from '@neodrag/core/plugins';

const engine = Neodrag.shared;
const handle = engine.draggable(element, [axis('x'), grid([10, 10])]);

handle.destroy();
engine.dispose();
```

### Constructor options

```typescript
new Neodrag({
  plugins?: DragPlugin[],
  dropPlugins?: DropPlugin[],
  delegate?: () => HTMLElement,
  onError?: (error: ErrorInfo) => void,
  dev?: boolean,
});
```

Use `Neodrag.shared` when you do not need a custom default plugin stack.

### `draggable(node, plugins?, options?)`

Returns a `DragHandle`. `plugins` is `DragPlugin[]` or `() => DragPlugin[]`; framework wrappers reconcile changes via `handle.update()`.

**Threshold** (movement / delay before drag starts) is configured per binding, not as a plugin:

```typescript
import { Draggable } from '@neodrag/core';

const drag = new Draggable({
  plugins: [axis('x')],
  threshold: { distance: 10, delay: 100 },
});

const immediate = new Draggable({ plugins: [], threshold: null });
```

| `threshold` | Behavior |
|-------------|----------|
| omitted | Default: **3px** distance, **0ms** delay |
| `null` | Start dragging on the first move |
| `{ delay?, distance? }` | Custom threshold |

Low-level API:

```typescript
engine.draggable(node, plugins, { threshold: { distance: 8 } });
```

### `droppable(node, plugins?)`

Returns a `DropHandle` for drop targets. Same reactive `PluginInput` shape as drag (`DropPlugin[]` or `() => DropPlugin[]`).

### `resizable(node, plugins?, options?)`

Returns a `ResizeHandle` for resize targets. **Numbers are always px.** CSS unit strings (`'10rem'`, `'50%'`) require opt-in per binding.

**`SizeInput` strings** must be a **single** length (`'10rem'`, `'92vw'`) — not `min()`, `max()`, `clamp()`, or `fr`. See **[Length & SizeInput](/docs/svelte/reference/length)** for units, types, and examples.

```typescript
import { Neodrag, Length } from '@neodrag/core';
import { resizeHandles, sizeBounds } from '@neodrag/core/resize';

const engine = Neodrag.shared;
engine.resizable(
  panel,
  [
    resizeHandles({ edges: ['e', 's', 'se'], size: '0.75rem' }),
    sizeBounds({ minWidth: '10rem', minHeight: 80 }),
  ],
  { length: new Length({ units: 'preserve' }) },
);
```

`length` is **not** on `Neodrag` / `Neodrag.shared` — each `draggable` / `resizable` / `Droppable` binding can pass its own adapter. Framework wrappers: `new Resizable({ length: new Length(), minSize: { width: 80, height: 40 }, plugins: [...] })`.

- **`new Length({ units: 'preserve' })`** (default): keep `%` / `rem` on `width` / `height` after resize.
- **`new Length({ units: 'px' })`**: always write px strings.
- **Custom adapters**: implement `LengthAdapter` or use `defineLengthAdapter` / `delegateLengthAdapter` with helpers (`parseLengthString`, `resolveUnit`, `lengthContext`, …) from `@neodrag/core`.

Built-in resize plugins live under `@neodrag/core/resize`. `ResizeCtx.length` resolves plugin sizes; `size` / `initial` are CSS strings, `sizePx` is layout px. Cancel restores authored size at pointer-down (`Escape` uses the keyboard sensor).

### Sensors (input layer)

Pointer and keyboard input are **sensors** registered on the engine (`registerSensor`), not per-draggable plugins. By default, `new Neodrag()` installs pointer, Escape-cancel, and keyboard-move sensors.

```typescript
import { Neodrag, PointerSensor } from '@neodrag/core';

const engine = new Neodrag(); // defaults installed

const pointerOnly = new Neodrag({ defaultSensors: false });
pointerOnly.registerSensor(new PointerSensor());
```

See **[Sensors](/framework/06-sensors)** for `registerSensor`, `unregisterSensor`, custom `SensorBase` subclasses, and built-in keys.

### Delegate target

`delegate` is read when sensors attach (first draggable/droppable). Neodrag is browser-only — wire it on elements that exist in the DOM.

Pass a custom delegate when you use `new Neodrag()` directly:

```typescript
import { Neodrag } from '@neodrag/core';

const engine = new Neodrag({
  delegate: () => document.documentElement,
});
```

### `dispose()`

Destroys all bindings and listeners on this engine.

## Plugins

Import built-in drag plugins from `@neodrag/core/plugins`. Drop helpers from `@neodrag/core/drop/plugins`; sortable from `@neodrag/core/drop`. Resize plugins from `@neodrag/core/resize`. In development, `installInteractionInspector(engine)` from `@neodrag/core/dev` overlays live drag/drop stats when `engine.dev` is true. Browser tests can use `@neodrag/test` (also re-exported from `@neodrag/core/testing`).

The main `@neodrag/core` entry exports the engine, types, and default plugin presets only — optional plugins are not pulled in unless you import them.

Custom plugins:

```typescript
import { defineDragPlugin } from '@neodrag/core';

export const myPlugin = defineDragPlugin(() => ({
  key: Symbol('my-plugin'),
  drag(ctx, state, event) {
    return { x: ctx.proposed.x, y: ctx.proposed.y };
  },
}));
```

Use a **named** `Symbol('…')` so `key.description` is readable in errors and devtools. With **`dev: true`** (the default outside production builds), anonymous `Symbol()` keys **throw** at attach time. Production (`dev: false`) allows anonymous symbols; identity is always `key`.

## Reactive updates

Framework packages accept `() => plugins` and call `Neodrag#update` internally. Vanilla callers invoke `handle.update(plugins)` when options change.

### Custom length adapters

```typescript
import {
  Length,
  defineLengthAdapter,
  parseLengthString,
  resolveUnit,
  lengthContext,
  type LengthAdapter,
} from '@neodrag/core';

export const designTokenLength: LengthAdapter = defineLengthAdapter({
  units: 'preserve',
  resolvePx(value, ctx) {
    if (typeof value === 'number') return value;
    if (value.startsWith('token-')) return resolveDesignToken(value);
    const { value: n, unit } = parseLengthString(value);
    return resolveUnit(n, unit, lengthContext(ctx.element, ctx.axis));
  },
  readAuthoredPair: (node) => new Length().readAuthoredPair(node),
  commitAuthored: (px, preserve, node) => new Length().commitAuthored(px, preserve, node),
  cloneAuthored: (pair) => ({ ...pair }),
});
```

Import built-in plugins from `@neodrag/core/plugins` (not from `@neodrag/svelte` / `@neodrag/react` main entries). Framework packages expose `@neodrag/*/plugins` re-exports for convenience only.
