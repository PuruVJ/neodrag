The core engine that powers all Neodrag framework implementations. Neodrag v3 uses a unified **`Neodrag`** class with a plugin-based drag and drop system.

## Installation

```sh
npm i @neodrag/core@next
```

## Overview

`@neodrag/core` implements tree-shakeable plugins, delegated pointer handling, and a single engine for both drag sources and drop targets. Framework packages (`@neodrag/svelte`, `@neodrag/react`, etc.) are thin wrappers around this API.

## Architecture

- **`Neodrag`**: Main engine — `new Draggable()`, `new Droppable()`, `dispose()`
- **Plugins**: `defineDragPlugin` / `defineDropPlugin` with lifecycle hooks
- **Event delegation**: Three global pointer listeners on the delegate element
- **Reactive reconcile**: wrappers call `engine.update` when plugin inputs change
- **`DragHandle`**: Per-element binding with `.update()` and `.destroy()`

## Neodrag

```typescript
import { Neodrag } from '@neodrag/core';
import { axis, grid } from '@neodrag/core/plugins';

const engine = Neodrag.shared;
const handle = engine.draggable(element, [axis('x'), grid([10, 10])]);

handle.destroy();
engine.dispose();
```

### Constructor options

```typescript
new Neodrag({
  plugins?: DragPlugin[],
  dropPlugins?: DropPlugin[],
  delegate?: () => HTMLElement,
  onError?: (error: ErrorInfo) => void,
  dev?: boolean,
});
```

Use `Neodrag.shared` when you do not need a custom default plugin stack.

### `draggable(node, plugins?)`

Returns a `DragHandle`. `plugins` is `DragPlugin[]` or `() => DragPlugin[]`; framework wrappers reconcile changes via `handle.update()`.

### `droppable(node, plugins?)`

Returns a `DropHandle` for drop targets. Same reactive `PluginInput` shape as drag (`DropPlugin[]` or `() => DropPlugin[]`).

### `resizable(node, plugins?)`

Returns a `ResizeHandle` for resize targets. Sizes are **px only** in v1. Built-in plugins live under `@neodrag/core/resize` (`resizeHandles`, `sizeBounds`, `aspectRatio`, `resizeEvents`, presets). Cancel restores the size at pointer-down (`Escape` uses the keyboard sensor).

```typescript
import { Neodrag } from '@neodrag/core';
import { resizeHandles, sizeBounds } from '@neodrag/core/resize';

const engine = Neodrag.shared;
engine.resizable(panel, [
  resizeHandles({ edges: ['e', 's', 'se'] }),
  sizeBounds({ minWidth: 120, minHeight: 80 }),
]);
```

Resize handles take pointer priority over drag on the same node when both are bound. Drop hit-testing follows layout after resize.

### Sensors (input layer)

Pointer and keyboard input are **sensors** on the engine — not hard-coded listeners. Default: `pointerSensor()` + `keyboardSensor()` (Escape cancels).

```typescript
import { Neodrag, defaultSensors, pointerSensor } from '@neodrag/core';

const engine = new Neodrag({
  sensors: defaultSensors(),
  // or pointer-only while building resize / multi-drag sensors:
  // sensors: [pointerSensor({ buttons: [0] })],
});
```

Custom sensors implement `setup(host) → cleanup` and call `SensorHost` (`onPointerDown`, `onPointerMove`, `onPointerUp`, `cancelActive`). Resize uses handle hit-testing on the existing pointer sensor path; dedicated resize sensors may follow for multi-drag.

### Delegate target

`delegate` is read when sensors attach (first draggable/droppable). Neodrag is browser-only — wire it on elements that exist in the DOM.

Pass a custom delegate when you use `new Neodrag()` directly:

```typescript
import { Neodrag } from '@neodrag/core';

const engine = new Neodrag({
  delegate: () => document.documentElement,
});
```

### `dispose()`

Destroys all bindings and listeners on this engine.

## Plugins

Import built-in drag plugins from `@neodrag/core/plugins`. Drop helpers from `@neodrag/core/drop/plugins`; sortable from `@neodrag/core/drop`. Resize plugins from `@neodrag/core/resize`. In development, `installInteractionInspector(engine)` from `@neodrag/core/dev` overlays live drag/drop stats when `engine.dev` is true. Browser tests can use `@neodrag/test` (also re-exported from `@neodrag/core/testing`).

The main `@neodrag/core` entry exports the engine, types, and default plugin presets only — optional plugins are not pulled in unless you import them.

Custom plugins:

```typescript
import { defineDragPlugin } from '@neodrag/core';

export const myPlugin = defineDragPlugin(() => ({
  key: Symbol('my-plugin'),
  drag(ctx, state, event) {
    return { x: ctx.proposed.x, y: ctx.proposed.y };
  },
}));
```

Use a **named** `Symbol('…')` so `key.description` is readable in errors and devtools. With **`dev: true`** (the default outside production builds), anonymous `Symbol()` keys **throw** at attach time. Production (`dev: false`) allows anonymous symbols; identity is always `key`.

## Reactive updates

Framework packages accept `() => plugins` and call `Neodrag#update` internally. Vanilla callers invoke `handle.update(plugins)` when options change.
