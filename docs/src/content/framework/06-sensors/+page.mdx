Sensors listen on the engine **delegate** (usually `document.documentElement`) and call into the session machine. They are **not** per-draggable plugins.

## Registration API

Sensors are **classes** extending `SensorBase`, registered on `Neodrag` via `registerSensor`. There is no `sensors: []` constructor option.

```typescript
import {
  Neodrag,
  PointerSensor,
  KeyboardSensor,
  KeyboardMoveSensor,
  KEYBOARD_MOVE_SENSOR_KEY,
  installDefaultSensors,
} from '@neodrag/core';

// Default: pointer + Escape cancel + keyboard move
const engine = new Neodrag();

// Pointer only
const pointerOnly = new Neodrag({ defaultSensors: false });
pointerOnly.registerSensor(new PointerSensor({ buttons: [0] }));

// Trim a default
const trimmed = new Neodrag();
trimmed.unregisterSensor(KEYBOARD_MOVE_SENSOR_KEY);

// Re-install built-ins after opting out
const custom = new Neodrag({ defaultSensors: false });
installDefaultSensors((sensor) => custom.registerSensor(sensor));
```

### `registerSensor(sensor)`

- Adds a sensor instance (`extends SensorBase`).
- Throws if another sensor with the same `key` is already registered.
- If listeners are already armed (after first binding), the sensor is set up immediately.

### `unregisterSensor(key)`

Runs cleanup and removes the sensor.

### `getSensors()`

Read-only list in registration order.

### `defaultSensors` engine option

| Value | Behavior |
|-------|----------|
| omitted / `true` | Registers `PointerSensor`, `KeyboardSensor`, `KeyboardMoveSensor` at construction |
| `false` | No sensors until you call `registerSensor` |

## Built-in sensor classes

| Class | Role |
|-------|------|
| `PointerSensor` | Pointer events → `InteractionInput` (`kind: 'pointer'`) |
| `KeyboardSensor` | `Escape` → `cancelActive('cancel')` |
| `KeyboardMoveSensor` | Space grab + arrows when `keyboardDrag` plugin is on the node |

## Custom sensor

```typescript
import { SensorBase, type SensorHost, keyboardToInput } from '@neodrag/core';

class MySensor extends SensorBase {
  readonly key = Symbol('my.sensor');

  protected attach(host: SensorHost) {
    const onMove = () => {
      host.onInteractionMove(
        keyboardToInput({ phase: 'move', clientX: 0, clientY: 0, key: 'ArrowRight', delta: { x: 1, y: 0 } }),
      );
    };
    // listen(...)
    return () => { /* cleanup */ };
  }
}

engine.registerSensor(new MySensor());
```

## Plugins vs sensors

| | Sensors | Plugins |
|---|---------|---------|
| Scope | Engine | Per draggable |
| Job | Input → `InteractionInput` | Bounds, grid, `keyboardDrag` config, etc. |

See [keyboard-drag](/plugin/14-keyboard-drag) for the keyboard grab model.
