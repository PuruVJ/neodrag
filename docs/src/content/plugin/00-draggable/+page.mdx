import FrameworkSwitch from '$components/FrameworkSwitch.astro';

Draggable is the core capability of Neodrag: pick up an element with a pointer (mouse, touch, or pen) and move it. You bind it to a node, optionally pass an options object, and read back whether it's currently dragging. Everything — the class/hook, every option, and the extensions — comes from your one framework package.

## Binding a draggable

Each framework exposes the same capability through its native idiom. There's nothing to import beyond the package itself.

<FrameworkSwitch>
<div slot="svelte">

In Svelte, `Draggable` is a **class**. Construct it in `<script>`, spread `{...drag.attach}` onto the element, and read `drag.isDragging`. Requires Svelte 5 (it's built on attachments).

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';

  const drag = new Draggable();
</script>

<div {...drag.attach}>Drag me</div>

{#if drag.isDragging}
  <p>Dragging…</p>
{/if}
```

</div>
<div slot="react">

The `useDraggable` hook owns the ref and returns it alongside `isDragging`. Put `ref` on the element.

```tsx
import { useDraggable } from '@neodrag/react';

function Box() {
  const { ref, isDragging } = useDraggable();
  return <div ref={ref}>{isDragging ? 'Dragging…' : 'Drag me'}</div>;
}
```

</div>
<div slot="vue">

The `useDraggable` composable returns a template `ref` and a reactive `isDragging`. Bind with `:ref`.

```vue
<script setup>
  import { useDraggable } from '@neodrag/vue';

  const { ref, isDragging } = useDraggable();
</script>

<template>
  <div :ref="ref">{{ isDragging ? 'Dragging…' : 'Drag me' }}</div>
</template>
```

</div>
<div slot="solid">

`createDraggable` returns a `ref` setter and `isDragging` as an `Accessor` — call it to read.

```tsx
import { createDraggable } from '@neodrag/solid';

function Box() {
  const { ref, isDragging } = createDraggable();
  return <div ref={ref}>{isDragging() ? 'Dragging…' : 'Drag me'}</div>;
}
```

</div>
<div slot="vanilla">

The class **is** the API. Note the node comes **first** here. Call `.update()` to change options and `.destroy()` to tear down.

```js
import { Draggable } from '@neodrag/vanilla';

const node = document.querySelector('.box');
const drag = new Draggable(node);

// later:
drag.update({ axis: 'y' });
drag.destroy();
```

</div>
</FrameworkSwitch>

## `bounds`

Constrain movement so the element can't escape a region. `bounds` accepts several shapes:

- `'parent'` — stay inside the offset parent's box.
- `'viewport'` — stay inside the visible window.
- an `HTMLElement` — stay inside that element's box.
- a rect literal `{ left, top, right, bottom }` — fixed coordinates.
- a function `() => rect` returning that shape — resolved at drag start, for dynamic bounds.

If the element is larger than the bounds on an axis, it pins to the start edge rather than producing an invalid clamp.

<FrameworkSwitch>
<div slot="svelte">

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';

  const parent = new Draggable({ bounds: 'parent' });
  const viewport = new Draggable({ bounds: 'viewport' });
  const rect = new Draggable({ bounds: { left: 0, top: 0, right: 400, bottom: 300 } });
  const dynamic = new Draggable({ bounds: () => document.querySelector('.zone').getBoundingClientRect() });
</script>

<div {...parent.attach}>Inside my parent</div>
```

</div>
<div slot="react">

## `handle`

Only start a drag when the pointer lands inside this handle. Pass a CSS selector (run through `querySelectorAll` against the node — use a trusted, static selector) or an `HTMLElement`. The whole element still moves; only the **grab point** is restricted.

  const drag = new Draggable({ controls: { handle: '.titlebar' } });

<div {...drag.attach} class="window">
  <div class="titlebar">Grab here</div>
  <p>Body — not a grab point</p>

## `disabled`

When `true`, a drag never starts. Toggle it from reactive state to turn dragging on and off — pass it as a getter (or just the latest value each render) so it updates live.

<FrameworkSwitch>
<div slot="svelte">

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';

  let locked = $state(false);
  const drag = new Draggable({ get disabled() { return locked; } });
</script>

<button onclick={() => (locked = !locked)}>{locked ? 'Unlock' : 'Lock'}</button>
<div {...drag.attach}>Drag me — unless locked</div>
```

</div>
<div slot="react">

```tsx
import { useState } from 'react';
import { useDraggable } from '@neodrag/react';

  const { ref } = useDraggable({ disabled: locked });
  return (
    <>
      <button onClick={() => setLocked((v) => !v)}>{locked ? 'Unlock' : 'Lock'}</button>
      <div ref={ref}>Drag me — unless locked</div>
    </>
  );
}
```

</div>

## `position`

The element's offset as `{ x, y }`. Pass it once for an **initial** position, or wire it to reactive state to **control** the element.

`position` is special. It is one of only **two bindable options** (the other is `size` on Resizable) — every other option is a **one-way input** you feed in (via a getter). `position` is the one that can flow **both ways**: feed it in to move the element, and let a drag write the live offset **back** into your state.

You opt into two-way binding by defining a `position` **getter/setter pair** on the options object. The getter feeds your state in; the setter receives the live offset on every move, keeping your state in sync with the drag. A getter-only `position` stays one-way (programmatic control, drag doesn't write back).

<FrameworkSwitch>
<div slot="svelte">

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';

  let position = $state({ x: 0, y: 0 });

  const drag = new Draggable({
    get position() { return position; },
    set position(v) { position = v; },
  });
</script>

<div {...drag.attach}>Drag me</div>
<p>x: {position.x}, y: {position.y}</p>
<button onclick={() => (position = { x: 0, y: 0 })}>Reset</button>
```

Dragging updates `position`; setting `position` (e.g. the Reset button) moves the element. Both directions stay in sync.

</div>
<div slot="react">

```tsx
import { useState } from 'react';
import { useDraggable } from '@neodrag/react';

function Box() {
  const [position, setPosition] = useState({ x: 0, y: 0 });
  const { ref } = useDraggable({
    get position() { return position; },
    set position(v) { setPosition(v); },
  });
  return (
    <>
      <div ref={ref}>Drag me</div>
      <p>x: {position.x}, y: {position.y}</p>
      <button onClick={() => setPosition({ x: 0, y: 0 })}>Reset</button>
    </>
  );
}
```

Dragging calls `setPosition`; setting `position` moves the element. Both directions stay in sync.

</div>

```vue

## Built-in behaviors: `touchAction` & `userSelect`

These two are the only **always-on** behaviors — every other option is opt-in. You usually never touch them; they just make touch and text-selection behave.

### `touchAction`

Sets the CSS `touch-action` on the node so a touch drag isn't hijacked by the browser as a native scroll or zoom. It's applied **at bind** (before the gesture can start) and is **axis-aware** by default:

- `axis: 'x'` → `'pan-y'` (the browser keeps vertical scroll, you get horizontal drag)
- `axis: 'y'` → `'pan-x'`
- free drag → `'none'`

Pass a custom string to override, or `false` to leave `touch-action` untouched.

### `userSelect`

Default `true` — sets `user-select: none` on the document body while a drag is active (and restores it on end), so text doesn't get highlighted as you drag. Set `false` to allow selection.

<FrameworkSwitch>
<div slot="svelte">

  // Defaults are sensible — only set these to opt out:
  const drag = new Draggable({ touchAction: false, userSelect: false });
</script>

```

</div>

## Events: `onDragStart`, `onDrag`, `onDragEnd`

Three callbacks fire over a drag's lifetime. Each receives a **`DragEventData`**:

```ts
type DragEventData = {
  offset: { x: number; y: number }; // the current offset
  node: HTMLElement | SVGElement;   // the dragged node
  input;                            // the normalized interaction input (pointer/keyboard/…)
};
```

`onDragStart` fires once the drag begins (after any `threshold`), `onDrag` on every move, and `onDragEnd` when it's released.

<FrameworkSwitch>
<div slot="svelte">

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';

  const drag = new Draggable({
    onDragStart: ({ offset }) => console.log('start', offset),
    onDrag: ({ offset }) => console.log('move', offset),
    onDragEnd: ({ offset }) => console.log('end', offset),
  });
</script>

<div {...drag.attach}>Drag me</div>
```

## Styling the dragged element

While a drag is active, Neodrag puts a `data-neodrag-dragging` attribute on the dragged node. Hook your styles onto it — no JS state needed.

```css
[data-neodrag-dragging] {
  cursor: grabbing;
  opacity: 0.9;
  box-shadow: 0 12px 30px rgb(0 0 0 / 0.25);
}
```

## Going further: `use`

For behaviors beyond the built-in options — magnetic snapping, scroll-locking, drag ghosts, haptics, ARIA announcements, or your own custom logic — pass a static array to the `use` option. These tier-2 extensions all import from your framework package. See [Extras](/docs/extras) for the full list, the authoring API, and the reactivity rule for `use`.
