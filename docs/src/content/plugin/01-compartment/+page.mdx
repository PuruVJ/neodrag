`Compartment` was removed in Neodrag v3 interactions. Pass reactive plugin lists from your framework wrapper instead — the wrapper calls `engine.update` when dependencies change.

## Svelte

```svelte
<script>
  import { Draggable } from '@neodrag/svelte'
	import { position } from '@neodrag/svelte/plugins';

  let pos = $state({ x: 0, y: 0 });

  const drag = new Draggable({ plugins: [() => position({ current: pos })] });
</script>

<div {@attach drag.attachment}></div>
```

## React

```tsx
const ref = useRef<HTMLDivElement>(null);
const [pos, setPos] = useState({ x: 0, y: 0 });

useDraggable(ref, () => [position({ current: pos })]);
```

## Vue

```vue
<div v-draggable="() => [position({ current: pos })]" />
```

## Vanilla

Call `handle.update([...])` when your app state changes.

See the [position](/plugin/07-position) plugin for two-way binding patterns.
