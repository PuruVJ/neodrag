Neodrag applies drag state attributes on every drag handle automatically. You do not need a plugin.

**Attributes:**

- `data-neodrag=""` — marks the element as a neodrag handle
- `data-neodrag-state="idle|dragging"` — current drag state
- `data-neodrag-count="0"` — number of completed drags (increments after each successful release)

On cancel, the count is not incremented and end-state attributes are not updated (same as the former `stateMarker` plugin’s `skipOnCancel` behavior).

## Svelte (reactive spreads)

Spread `drag.target` so SSR and runtime share the same attrs. The Svelte binding keeps `$state` in sync when the engine updates markup:

<FrameworkSwitch>
<div slot="svelte">

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';

  const drag = new Draggable({ plugins: [] });
</script>

<div {...drag.target}>
  Drag me — watch `data-neodrag-state`
</div>
```

</div>

<div slot="react">

```tsx
import { useRef } from 'react';
import { dragTargetAttrs, useDraggable } from '@neodrag/react';

function Example() {
  const elementRef = useRef<HTMLDivElement>(null);
  useDraggable(elementRef, []);

  return (
    <div ref={elementRef} {...dragTargetAttrs()}>
      Drag me — attributes update on the DOM automatically
    </div>
  );
}
```

</div>

<div slot="vue">

```vue
<script setup>
import { dragTargetAttrs } from '@neodrag/core';
import { vDraggable } from '@neodrag/vue';
</script>

<template>
  <div v-draggable="[]" v-bind="dragTargetAttrs()">
    Drag me
  </div>
</template>
```

</div>

<div slot="solid">

```tsx
import { createSignal } from 'solid-js';
import { dragTargetAttrs, createDraggable } from '@neodrag/solid';

function Example() {
  const [element, setElement] = createSignal<HTMLElement | null>(null);
  createDraggable(element, []);

  return <div ref={setElement} {...dragTargetAttrs()}>Drag me</div>;
}
```

</div>

<div slot="vanilla">

```typescript
import { dragTargetAttrs, Neodrag } from '@neodrag/core';

const element = document.getElementById('draggable')!;
Object.assign(element, dragTargetAttrs());
Neodrag.shared.draggable(element, []);
```

</div>
</FrameworkSwitch>

## Styling by state

```css
[data-neodrag-state='dragging'] {
  opacity: 0.85;
  cursor: grabbing;
}

[data-neodrag-count='0'] {
  outline: 1px dashed var(--accent);
}
```

Drag state attributes are owned by the engine and `MarkupAdapter`. Do not add a plugin for them.
