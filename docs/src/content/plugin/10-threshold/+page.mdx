---
title: 'threshold (removed)'
nav_title: 'threshold'
tagline: 'Threshold is now a Draggable option, not a plugin.'
---

The `threshold()` plugin was removed in v3. Configure threshold on **`Draggable`** or `engine.draggable()` instead.

```typescript
import { Draggable } from '@neodrag/core';

const drag = new Draggable({
  plugins: [axis('x')],
  threshold: { distance: 10 },
});

const noThreshold = new Draggable({ plugins: [], threshold: null });
```

See **[@neodrag/core — draggable options](/framework/05-core)** for defaults and API details.
