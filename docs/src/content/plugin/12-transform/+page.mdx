---
title: 'Visual movement'
tagline: 'Built into the engine — use applyTransform for custom effects'
---

Neodrag applies drag movement to the DOM automatically. You do **not** add a transform plugin.

By default, HTML elements get a `translate(x, y)` style and SVG elements get a `transform` attribute. This runs on every drag frame and after plugin updates (for example when the [position](/plugin/07-position) plugin changes coordinates).

## Custom movement (Svelte)

Pass `applyTransform` when you need scale, rotate, or other effects:

```svelte
<script>
  import { Draggable } from '@neodrag/svelte';
  import { axis } from '@neodrag/svelte/plugins';

  const drag = new Draggable({
    plugins: [axis('x')],
    applyTransform: ({ offset, rootNode }) => {
      rootNode.style.transform = `translate(${offset.x}px, ${offset.y}px) rotate(5deg)`;
    },
  });
</script>

<div {@attach drag.attachment}>Custom visual</div>
```

## React

`useDraggable` does not expose `applyTransform` yet — use `new Draggable` from `@neodrag/react` (re-exported from core) or the vanilla engine for custom appliers.

## Vanilla

```typescript
import { Draggable } from '@neodrag/vanilla';

const drag = new Draggable({
  plugins: [axis('x')],
  applyTransform: ({ offset, rootNode }) => {
    rootNode.style.transform = `translate(${offset.x}px, ${offset.y}px)`;
  },
});

drag.attach(document.querySelector('#box')!);
```

## Low-level engine

`Neodrag.shared.draggable(node, plugins, { applyTransform })` accepts the same optional third argument when not using the binding class.
