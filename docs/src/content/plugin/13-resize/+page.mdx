Resize is a separate interaction from drag: pointer math stays in **pixels**, while DOM `width` / `height` can stay in **px**, **%**, **rem**, etc. when you opt in with a length adapter.

Built-in plugins live under `@neodrag/core/resize` (and framework `/resize` re-exports).

## Opt-in CSS lengths

Numbers in plugin options are always **px**. Strings like `'10rem'` or `'50%'` require `length: new Length()` on the **binding** (not on `Neodrag.shared`).

### SizeInput

Any option typed as `SizeInput` (bounds, handle `size`, grid steps, etc.) accepts:

- a **number** — treated as **px**, or
- a **single CSS length string** — one numeric token glued to one supported unit.

TypeScript models that as `CssLengthString`:

```typescript
import type { CssLengthString, CssLengthUnit, SizeInput } from '@neodrag/core';

// `${number}${unit}` — examples that type-check:
const a: CssLengthString = '10rem';
const b: CssLengthString = '92vw';
const c: CssLengthString = '-4px';

// These do NOT satisfy CssLengthString (and throw at runtime if passed anyway):
// 'min(92vw, 720px)'
// 'clamp(200px, 50%, 800px)'
// '1fr' | 'auto' | '10 px' (space before unit)
```

**Supported units** (same list as `CSS_LENGTH_UNITS` in `@neodrag/core`):

`px` · `%` · `rem` · `em` · `ch` · `ex` · `vw` · `vh` · `vmin` · `vmax` · `svw` · `svh` · `lvw` · `lvh` · `dvw` · `dvh`

**Not supported yet:** CSS math (`min()`, `max()`, `clamp()`, `calc()`), grid `fr`, keywords (`auto`, `fit-content`), or multi-value strings. Use a plain number for a px cap, pick one unit (e.g. `'92vw'`), or compute the limit in JavaScript and pass a number.

**Widened strings:** a value typed as `string` is not checked. Prefer literals, `as const`, or keep the variable typed as `CssLengthString` / `SizeInput`.

**Without `Length`:** only numbers work; unit strings throw with a hint to add `length: new Length()`.

import { Length } from '@neodrag/core';
import { Resizable } from '@neodrag/react';
import { resizeHandles, sizeBounds } from '@neodrag/react/resize';
import { useRef, useMemo } from 'react';

        ],

  );

}

- **`new Length({ units: 'preserve' })`** (default): after resize, keep authored units (`50%` stays `%`).
- **`new Length({ units: 'px' })`**: always write px strings.
- **Cancel** (`Escape` via keyboard sensor): restores size at pointer-down.

### `minSize` / `maxSize` on `Resizable`

Framework `Resizable` bindings (and `ResizableOptions` in core) accept bounds without a separate plugin:

```typescript
new Resizable({
  length: new Length(),
  minSize: { width: 220, height: 140 },
  maxSize: { width: '92vw', height: '82vh' },
  // minSize: 40 — shorthand: same limit on width and height
  plugins: [resizeHandles({ edges: 'all' })],
});
```

Values follow the same **`SizeInput`** rules above. This injects `sizeBounds` for you; if you also pass `sizeBounds()` in `plugins`, the binding options win.

## Plugins

| Plugin | Purpose |
|--------|---------|
| `resizeHandles` | Creates edge/corner handles (`data-neodrag-resize-handle`) |
| `sizeBounds` | `minWidth` / `maxWidth` / `minHeight` / `maxHeight`, optional `parent` clamp (or use `minSize` / `maxSize` on `Resizable`) |
| `resizeAxis` | Lock to `'x'`, `'y'`, or `'both'` |
| `aspectRatio` | Fixed ratio or `'preserve'` initial ratio |
| `resizeEvents` | `onStart` / `onResize` / `onEnd` with `size`, `sizePx`, `initial` |

## Presets

```typescript
import { presetPanel, presetCornerBox, presetSplitPane } from '@neodrag/core/resize';

presetSplitPane('x'); // east handle + axis lock + min size
```

## With drag on the same node

Resize handles take **pointer priority** over drag on the same element. Use separate drag handles (e.g. `controls`) or attach drag to a child — see the core resize + drag integration tests.

## Tailwind / utility classes

Neodrag plugins accept **CSS lengths**, not Tailwind class names (`w-10` is not `10px`). Style the element with utilities; pass matching CSS in plugins (`'50%'`, `'10rem'`) or use theme CSS variables. Automatic utility lookup is not built into core.

## Sensors

Resize uses the same **pointer sensor** path as drag. `KeyboardSensor` (default on `Neodrag`) cancels an active resize with `Escape`. Dedicated resize-only sensors are not required for basic use.
