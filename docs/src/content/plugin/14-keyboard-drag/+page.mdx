Keyboard dragging is **additive**: `pointerSensor` stays the default pointer path. A `keyboardMoveSensor` submits `InteractionInput` with `kind: 'keyboard'` (no synthetic `PointerEvent`).

## Plugins

- **`keyboardDrag`** — registers step, axis, and hold-repeat tuning on the draggable node.
- **`ariaDrag`** — `tabindex`, `role`, `aria-grabbed`, optional live region announcements.

Use `defaultSensors()` (includes pointer, Escape cancel, and keyboard move) or add `keyboardMoveSensor()` explicitly.

## Grab model

1. Focus the draggable.
2. **Space** toggles grab.
3. **Arrow keys** move by `step` (with slow → fast repeat after `speedupDelay`).
4. **Space** again or **Escape** ends the session.

## InteractionInput

Plugin hooks receive `input: InteractionInput` instead of `PointerEvent`. Use `input.clientX` / `input.clientY` for all kinds, or `input.kind === 'pointer'` when you need hit-testing on `input.native`.

See `@neodrag/core/interaction` for builders (`pointerToInput`, `keyboardToInput`) and guards.
