`Swipeable` is the swipe-to-dismiss gesture — a list row you flick away, a card you toss off-screen. The element follows the pointer along one axis; released **past the threshold** it animates the rest of the way out and fires `onDismiss`, and released short of it springs back to rest. It's built on the core `Draggable`, so it gets the same pointer-capture and sensors as any drag.

## Anatomy

Bind the element, read `offset` / `isDismissed`, and (optionally) handle `onDismiss`. `reset()` springs a dismissed element back so you can re-show it.

## Options

Pass these to the constructor / hook:

| key | type | meaning |
|---|---|---|
| `axis` | `'x'` (default) \| `'y'` | the swipe direction |
| `threshold` | `number` | dismiss distance — a **fraction** of the element's size when `<= 1` (default `0.4`), otherwise an absolute px distance |
| `duration` | `number` | settle animation duration in ms (spring-back or fly-out). Default `220` |
| `onDismiss` | `(direction: -1 \| 1) => void` | fires after the element flies out; `-1` is left/up, `1` is right/down |

The instance exposes reactive `offset` (live px) and `isDismissed`, plus `reset()` to spring a dismissed element back to rest. The decision is also available as a pure function — `resolveSwipe(offset, size, threshold)` — and the framework-agnostic binder lives at `@neodrag/core/swipe` (`Swipeable`).
